# 대한상공회의소 매일유업 2기

> 일자리마다 **매달 실제로 남는 돈**을 비교하고, 정착까지 계획해 주는 AI 에이전트

2026 대한민국 청년 CAREER FAIR AI 해커톤 — "AI 에이전트로 푸는 청년의 일·생활 문제"

## 왜 만들었나요

취업이나 이주를 고민할 때 연봉만 보고는 판단하기 어렵습니다. 같은 연봉이어도 세금, 주거비, 교통비, 받을 수 있는 청년 지원에 따라 매달 손에 남는 돈이 크게 달라지기 때문입니다.

## 무엇을 하나요

- 공고 캡처, PDF, 엑셀, 텍스트 등 어떤 형식이든 올리면 비교표로 정리합니다
- 거주지, 교통비처럼 빠진 정보는 되물어서 채웁니다
- 공공데이터로 지역 주거비와 청년 지원 제도를 찾아봅니다
- '지금 집에서 통근' vs '이사', '수도권' vs '지역 잔류'의 월 예상 잔여액을 계산합니다
- 연봉이 공개되지 않은 공고는 "같은 금액이 남으려면 최소 얼마"인지 보여줍니다
- 자격이 되는 청년 지원 신청 순서와 마감을 담은 1년 정착 플랜을 만듭니다

숫자는 코드로 계산하고, 모든 값에 출처와 신뢰도(확인 / 추정 / 사용자 입력)를 표시합니다.
